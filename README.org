#+title: dotfiles
#+author: Tony Boetto

Personal dotfiles managed with [[https://www.gnu.org/software/stow/][GNU Stow]].

* Packages

| Package   | Description                                        |
|-----------+----------------------------------------------------|
| =audio=   | PipeWire and PulseAudio daemon configuration       |
| =claude=  | Claude Code global instructions (CLAUDE.md)        |
| =desktop= | Browser flags and fontconfig                       |
| =emacs=   | GNU Emacs configuration (literate, modular)        |
| =music=   | MPD and ncmpcpp configuration                      |
| =nvim=    | Neovim configuration                               |
| =scripts=       | Shared scripts that work on Linux and macOS      |
| =scripts-linux= | Linux-only scripts (X11, pacman, statusbar, cron) |
| =scripts-macos= | macOS-only scripts                               |
| =shell=   | Zsh, profile, aliases, and shell bookmarks         |
| =x11=     | X initialization, xprofile, xresources, xsession  |

* Installation

** Prerequisites

*Arch Linux*

#+begin_src sh
sudo pacman -S stow
#+end_src

*macOS*

#+begin_src sh
brew install stow
#+end_src

** Deploy a single package

#+begin_src sh
stow emacs
#+end_src

** Deploy all packages

*Linux*

#+begin_src sh
stow audio claude desktop emacs music nvim scripts scripts-linux shell x11
#+end_src

*macOS*

#+begin_src sh
stow claude emacs nvim scripts scripts-macos shell
#+end_src

Stow creates symlinks from =~= into the corresponding package directory.
Run from the root of this repository (i.e. =~/dotfiles=).

* Package notes

** claude

Symlinks to =~/.claude/CLAUDE.md=. Kept free of anything specific to a
work enterprise or private repo, since this file is tracked in a personal
dotfiles repo; repo-specific instructions belong in that repo's own
=AGENTS.md= or =CLAUDE.md= instead.

** emacs

Literate configuration lives in =emacs/.config/emacs/my-init.org=. Feature
modules are loaded from =tony-emacs-modules/= and custom lisp from
=tony-lisp/=. Uses [[https://github.com/progfolio/elpaca][Elpaca]] as the package manager.

** nvim

Entry point is =nvim/.config/nvim/init.lua=. Uses [[https://github.com/wbthomason/packer.nvim][packer.nvim]] for plugins.

** scripts

Scripts are symlinked into =~/.local/bin/=. They are split by OS so a
machine only stows what it can run: =scripts= is shared, =scripts-linux= is
Linux only, and =scripts-macos= is macOS only. All three use the same
=.local/bin/= layout, so they merge into one =~/.local/bin=. Statusbar
scripts live under =scripts-linux/.local/bin/statusbar/= and are designed
for use with =dwmblocks= or similar.

=scripts-linux/.local/bin/cron/fcrontab= is a plain-text source file, not an executable script — it's
the weekly mirror-ranking/npm-update schedule. Stowing it only places the
file; it still needs loading into fcron's spool with =fcrontab
~/.local/bin/cron/fcrontab= on each machine (see =linux-tricks.org= for the
full fcron setup).

** shell

Zsh config is at =~/.config/zsh/.zshrc=. Aliases are in
=~/.config/shell/aliasrc=. The =XDG_CONFIG_HOME= layout requires
=ZDOTDIR=$HOME/.config/zsh= to be set in =~/.zshenv= (or equivalent).
